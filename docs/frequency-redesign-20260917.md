# 실내건축기능사 핵심요약 중요도 재설계 보고서

- 대상: 기출핵심요약 100
- 입력: 2017~2025 공개 복원 660문항
- 2026 성안당 주제 자료: 실제 빈도 계산 제외
- 연도별 상한: 적용하지 않음

## 변경 기준
1. 반복 출제 핵심 유형과 단독 출제 참고를 분리
2. 빈도점수와 최신점수 분리
3. 최신점수는 빈도점수에 곱하지 않고 표시만 함
4. 반복 유형 우선, 이후 실제 빈도·출제 연도 수·실제 횟수·안정 ID 순 정렬
5. 동점 정렬은 입력 순서와 무관

## 결과
- 핵심요약 항목: 100
- 반복 출제 핵심 유형: 31
- 단독 출제 참고: 69
- 정답 줄: 100
- 출제빈도 줄: 100
- 연결 문항: 136
- 2024년 연결 문항: 19 (14.0%)
- 2026년 핵심요약 포함: 0
- 단독 후보: 기존 선정 69개 유지 후 단독우선점수로 재정렬
- 단독우선점수: 관련개념 출제연도수×3 + 관련개념 실제 출제횟수 + 핵심성×2 + 수치·규정성 + 기출 활용성
- 단독 관련개념은 구체 개념 키만 사용하며, 기타·일반 공통어는 0회 처리
- 단독우선점수 범위: 5~59
- 단독 점수 내림차순 검증: 통과
- 후보 보존·메타데이터 일치 검증: 통과
- 관련 테스트: 96개 전체 통과

기존 2024년 연결 비중 62.5%는 최신 단독문항이 동점 처리에서 앞서 들어간 구조적 편중이었다. 반복 유형은 실제 빈도 우선으로 유지하고, 단독 69개는 기존 후보를 바꾸지 않은 채 관련 개념 빈도·핵심성·수치/규정성·활용성으로 재정렬했다. 연도별 상한은 적용하지 않았다.
