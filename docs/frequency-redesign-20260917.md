# 실내건축기능사 핵심요약 중요도 재설계 보고서

- 대상: 기출핵심요약 100
- 입력: 2017~2025 공개 복원 660문항
- 2026 성안당 주제 자료: 실제 빈도 계산 제외
- 연도별 상한: 적용하지 않음

## 변경 기준
1. 반복 출제 핵심 유형과 단독 출제 참고를 분리
2. 빈도점수와 최신점수 분리
3. 최신점수는 빈도점수에 곱하지 않고 표시만 함
4. 반복 유형 우선, 이후 실제 빈도·출제 연도 수·실제 횟수·안정 ID 순 정렬
5. 동점 정렬은 입력 순서와 무관

## 결과
- 핵심요약 항목: 100
- 반복 출제 핵심 유형: 31
- 단독 출제 참고: 69
- 정답 줄: 100
- 출제빈도 줄: 100
- 연결 문항: 136
- 2024년 연결 문항: 19 (14.0%)
- 2026년 핵심요약 포함: 0
- 관련 테스트: 29개 통과

기존 2024년 연결 비중 62.5%는 최신 단독문항이 동점 처리에서 앞서 들어간 구조적 편중이었다. 수정 후 최신성은 참고용으로만 남기고 실제 출제빈도 우선으로 정렬했다.
